# Stay Available

Downloads for **Stay Available**, a small desktop utility for Windows and macOS. Start a timed session to keep your screen awake, with optional mouse movement after the computer has been idle.

## Download

Get the latest version from [Releases](https://github.com/Mohammad-Houry1/stay-available/releases). Each release lists its files with SHA-256 checksums.

- **Windows x64:** run `Stay-Available-<version>-Windows-x64-Setup.exe`. The installer is not code-signed yet, so Windows SmartScreen may ask you to confirm.

This repository holds release files only; the source code is not public. Releases here are immutable: a published version's files never change.
